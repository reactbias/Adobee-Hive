# Brand font

Drop `Mannin.woff2` (or `Mannin.otf`) here. It comes from
https://www.1001fonts.com/mannin-font.html by Cristiano Sobral, marked free for
personal and commercial use under the licence file in the zip (LICENCE_UFL.txt).
Keep that licence file next to the font. Until the file is here the site falls
back to Georgia for headings.
