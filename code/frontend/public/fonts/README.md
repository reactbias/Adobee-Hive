Why the new name: the Ubuntu Font Licence asks that a modified version (subsetting and converting count) keeps the
original name and adds "derivative X". The copyright notice stays in the file's metadata.

`public/brand/wordmark.svg` embeds a Bold-only subset of the same font, under the same licence.
