Hive hiring, step by step

1. Pick or edit a posting. 2. The people who fit follow it. 3. Choose to let the agents talk. 4. Read the interview. 5. See the ranking.

3Let the agents talk

Nothing has been asked of anyone yet. The recruiter's agent asks each person's agent the posting's questions. A person's agent answers only if its owner said yes, and only from the files that owner shared. Press the button when you want that to happen.
